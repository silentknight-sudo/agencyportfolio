# Stitch AI prompts: StudioAdsPro project covers

Paste the **master prompt** once, then send each project prompt one at a time (or in batches of 4–5).

## Master prompt (paste first)

```
Design a set of portfolio cover images for StudioAdsPro, an Indian digital agency doing Meta Ads, websites, apps/custom software and social media content.

Visual system (apply to every image):
- Format: 16:10 landscape hero image, also safe to crop to 21:9 and 4:3 (keep the key subject centred, keep the bottom-left 35% calm because a project title is overlaid there in white).
- Style: premium editorial agency portfolio, like Awwwards case-study covers. Clean, minimal, high contrast, soft studio lighting, subtle film grain.
- Palette: near-black #0B0B0B and off-white #F5F5F2 base, with ONE rich accent colour per project (given below).
- Show the work as real device mockups where relevant: iPhone showing an Instagram Reel/ad, laptop or browser window showing a website, phone + desktop pair for apps, dashboard for software.
- Indian context: Indian people, Indian products, Indian cities/architecture where it fits. Authentic, not stocky.
- No logos of Meta/Instagram/Apple. No text other than the client name if it naturally appears on the screen UI. No watermarks.

Discipline cues:
- META ADS → phone mockup of a sponsored Instagram Reel / carousel ad, floating ad cards, a small upward results chart.
- WEBSITE → large browser/laptop mockup of the homepage, with a phone showing the mobile version.
- APP / SOFTWARE → 2–3 phone screens fanned out, or a desktop dashboard + phone pair.
- SOCIAL → grid of 6–9 Reel thumbnails / vertical video frames on a phone and floating around it.

Generate one image per project prompt I send next.
```
